# Doki-Privacy-Policy
Doki Privacy Policy

Doki respects your privacy. This application stores user settings, character settings, chat history, and voice configuration locally on your device.

When you enable AI chat or voice features, the text you submit and related configuration may be sent to the third-party service provider selected by you, such as an AI model or text-to-speech provider. These services are used only to generate chat replies or speech audio.

Doki does not sell your personal data. Doki does not upload local files without your action. API keys entered by the user are stored locally and used only to call the service provider configured by the user.

Users may clear local chat history, memory, and settings in the application at any time.

Doki 隐私政策

Doki 尊重并保护用户隐私。本应用会在用户本地设备上保存应用设置、角色设置、聊天记录、记忆数据和语音配置。

Doki 不会出售用户个人数据，不会在未经用户操作的情况下上传本地文件。用户填写的 API Key 仅保存在本地，并仅用于调用用户配置的服务提供商。

用户可以随时在应用中清除本地聊天记录、记忆和相关设置。
